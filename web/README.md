# RepEngine Web Studio (`web`)

The desktop routine architect and analytics dashboard for **RepEngine**, built with **SvelteKit** (using **Svelte 5 Runes**), **TypeScript**, and **TailwindCSS**.

It is engineered for fast, intuitive routine programming, deep volume analytics, hands-free interval execution, and frictionless data export/import with the mobile companion.

---

## 🎨 Key Features

### 🛠️ Visual Block Studio & Progressions
* **Svelte 5 Runes**: Built using modern `$state`, `$derived`, and `$effect` primitives for fine-grained reactivity without store boilerplate.
* **Contextual Block Canvas**: Assemble multi-week training programs using modular blocks (`exercise`, `exercise_timed`, `section`, `rest`, `repeat`).
* **Connected Progression Sub-blocks**: Exercises include visual badges and inline controls for configured progression schemes (**Linear Progression** and **Double Progression**), replacing detached legacy nodes.
* **Transactional Undo/Redo**: Full in-memory history stack with keyboard shortcuts (`Ctrl+Z`, `Ctrl+Y`) and deep-cloned state snapshots.

### 📥 Canonical Routine JSON Hub
* **1-Click Export**: Export complete training programs as portable, human-readable JSON files.
* **Smart Import**: Paste or upload JSON templates with real-time schema validation (v1 standard), automatic exercise mapping, and visual preview before saving.
* **Seamless AI Prompt Interop**: Accepts structured routines generated by LLMs and converts them into active RepEngine workflows.

### ⏱️ Hands-Free Web Audio Interval Engine
* **Native Web Audio Synthesizer**: Generates crisp sound cues (countdown beeps, sprint sirens, rest alerts) without external media files or playback latency.
* **Multi-Phase Protocols**: Parses protocols like `30s work / 15s sprint / 15s rest` or shorthand notation (`30/15/15`, Tabata `20/10`), advancing automatically.
* **Screen Wake Lock Integration**: Keeps displays awake during rest intervals using the browser's Native Wake Lock API.

### 📊 Pure SVG Analytics
* **Zero Bloat**: Native SVG chart rendering with coordinate projection computed on the fly.
* **Progression Insights**: Interactive charts displaying total volume, estimated 1RM trends, and RPE/RIR drift over time.

## 🏗️ Project Structure

```
web/src/
├── lib/
│   ├── components/       # Reusable UI controls, modals, and navigation bars
│   │   ├── blocks/       # Visual routine block renderers (BlockExercise, etc.)
│   │   ├── charts/       # Pure SVG volume and progression chart renderers
│   │   └── modals/       # Routine JSON Hub modal, block picker, export sheets
│   ├── engine/           # Web Audio synthesizer, interval parser, timer state
│   └── stores/           # Undo/redo stack, optimistic concurrency manager
└── routes/
    ├── (app)/            # Authenticated application views (Dashboard, Studio, Player)
    └── (auth)/           # Login and athlete registration flows
```

## 🛠️ Development & Tooling

### Prerequisites
* Node.js (v20+ or v22+)
* npm (or pnpm)
* Running RepEngine Go API (`http://localhost:8080`)

### Useful Commands

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run TypeScript and Svelte syntax check
npm run check

# Build production bundle
npm run build

# Preview production build locally
npm run preview

# Run Playwright end-to-end integration tests
npx playwright test
```
