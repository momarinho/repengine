# RepEngine Web Studio (`web`)

The desktop routine architect and mobile-ready execution platform for **RepEngine**, built with **SvelteKit** (using **Svelte 5 Runes**), **TypeScript**, and **TailwindCSS**.

It is engineered for fast, intuitive routine programming, deep volume analytics, hands-free interval execution, and frictionless data export/import with the native mobile companion.

---

## 🎨 Key Features

### 🛠️ Visual Block Studio & Progressions
* **Svelte 5 Runes**: Built using modern `$state`, `$derived`, and `$effect` primitives for fine-grained reactivity without store boilerplate.
* **Contextual Block Canvas**: Assemble multi-week training programs using modular blocks (`exercise`, `exercise_timed`, `section`, `rest`, `repeat`, `wave`).
* **Connected Progression Sub-blocks**: Exercises include visual badges and inline controls for configured progression schemes (**Linear Progression** and **Double Progression**), replacing detached legacy nodes.
* **Transactional Undo/Redo**: Full in-memory history stack with keyboard shortcuts (`Ctrl+Z`, `Ctrl+Y`) and deep-cloned state snapshots.

### 📱 Responsive Mobile Workflows & Preview
* **Thumb-Friendly Touch Targets**: Stepper buttons (`-5`, `-2.5`, `+2.5`, `+5`) and inputs dynamically scale to fit small mobile viewports (320px–430px) without horizontal clipping or overflow.
* **Responsive Template Previews**: The Template Preview screen (`/templates/[id]`) features a compact 2x2 metadata grid and responsive section cards, eliminating unnecessary vertical scrolling on smartphones.
* **Read-Only Routine Outlines**: Fast-loading read-only routine preview tabs in the Editor and Player let athletes inspect exercise orders, set counts, and prescribed loads before lifting.
* **Mobile-Aware Layouts**: Studio workspace headers and action bars intelligently collapse into multi-row touch bars on small screens while retaining quick access to **Play**, **QR Discovery**, **JSON Hub**, and **Save**.

### 🎨 Theme System & Color Contrast Integrity
* **Atelier Kanagawa Dark & Light Themes**: Cohesive palette featuring high-contrast typography, deep surface containers, and soft neon accents.
* **Global Design Tokens**: Standardized `.btn-primary-gradient` token providing high-contrast text across both dark mode (`#3f0019` on `#ffb1c3`–`#eb6f92`) and light mode (`#ffffff` on `#eb6f92`–`#d15177`).
* **Autofill & Form Element Resilience**: Styled `-webkit-autofill` states and native `<select option>` elements to prevent browser-injected white backgrounds and unreadable text.

### 🔐 Distinct Authentication Workflows
* **Separated Sign In & Register Views**: Clean segmented navigation between `/login` and `/register` with clear page titles, dedicated submit buttons (`Sign In to RepEngine` vs `Create Your Account`), and password requirements helper text.

### 📥 Canonical Routine JSON Hub
* **1-Click Export**: Export complete training programs as portable, human-readable JSON files adhering to the Canonical Routine Schema v1.
* **Smart Import**: Paste or upload JSON templates with real-time schema validation, automatic exercise mapping, and visual preview before saving.
* **Seamless AI Prompt Interop**: Accepts structured routines generated by LLMs (ChatGPT, Claude, Gemini) and converts them into active RepEngine workflows.

### ⏱️ Hands-Free Web Audio Interval Engine
* **Native Web Audio Synthesizer**: Generates crisp sound cues (countdown beeps, sprint sirens, rest alerts) without external media files or playback latency.
* **Multi-Phase Protocols**: Parses protocols like `30s work / 15s sprint / 15s rest` or shorthand notation (`30/15/15`, Tabata `20/10`), advancing automatically.
* **Screen Wake Lock Integration**: Keeps displays awake during workouts and rest intervals using the browser's Native Wake Lock API.
* **Haptic Vibration**: Provides tactile countdown pulses on supported mobile devices.

### 📊 Pure SVG Analytics
* **Zero Bloat**: Native SVG chart rendering with coordinate projection computed dynamically on the client.
* **Progression Insights**: Interactive charts displaying total volume, estimated 1RM trends, and RPE/RIR drift over time.

## 🏗️ Project Structure

```
web/src/
├── app.css                   # Global theme tokens, typography, gradients & autofill overrides
├── app.html                  # HTML template with dark theme initialization & font imports
├── service-worker.ts         # PWA caching & offline asset shell
├── lib/
│   ├── analytics/            # Types & calculations for routine volume and progression trends
│   ├── blocks/               # Svelte 5 block renderers (BlockExercise, Timed, Linear, Wave, Rest)
│   ├── components/           # Reusable UI (AnalyticsChart, ScientificInsights, AI Architect, JSON Hub, QR)
│   ├── editor/               # Studio canvas state, normalization, Canonical JSON v1 engine
│   ├── player/               # Gym player routines, multi-day cycle scheduler, load overrides
│   ├── progression-states/   # Progression rules, double progression, and load calculation models
│   ├── sections/             # Block group & section hierarchy helpers
│   ├── server/               # SSR API client proxy helpers
│   ├── stores/               # Session & authentication stores
│   ├── templates/            # Template normalization & clone job polling
│   └── workout-sessions/     # Session state & set log schemas
└── routes/
    ├── (protected)/          # Authenticated routes (Dashboard, Templates, Editor, Player HUD, History, Settings)
    ├── login/                # Dedicated, high-contrast Sign In view
    ├── register/             # Dedicated, high-contrast Create Account view
    ├── forgot-password/      # Password reset request flow
    └── reset-password/       # Token-based password recovery
```

## 🛠️ Development & Tooling

### Prerequisites
* Node.js (v20+ or v22+)
* npm (v10+)
* Running RepEngine Go API (`http://localhost:8080`)

### Useful Commands

```bash
# Install dependencies
npm ci

# Start local development server with hot reload
npm run dev

# Run TypeScript and Svelte syntax check
npm run check

# Run unit test suite (Node native test runner)
npm test

# Build production bundle
npm run build

# Preview production build locally
npm run preview

# Run Playwright end-to-end integration tests
npx playwright test
```
